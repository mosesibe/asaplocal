# Customer app splash — design source

Working files behind the "AsapLocal Splash" design canvas.

Each `.dc.html` is one artboard (phone 390×844); `canvas.json` lays them out.
`logo-mark.svg` is not copied here — it is taken from
`apps/web/public/logo-mark.svg` at seed time so the two can never diverge.

- `Main.dc.html`       Direction A — trade ticker (leading candidate)
- `RadarSweep.dc.html` Direction B — radar sweep
- `IconRest.dc.html`   the resting hand-off frame

Tokens are lifted from `packages/ui/tailwind.preset.js` (Inter, brand
terracotta #c15f2a, espresso ground hsl(20 35% 7%)). Edit these files and
re-seed to update the canvas — never hand-edit the published page.
